# Óscar López Ruiz — personal website

Static site published with GitHub Pages at https://olopezr.github.io/web/

- `index.html` — Spanish version (default)
- `en/index.html` — English version. Content changes must be made in both files.
- `cv.html` — source of the CV; `.github/workflows/cv-pdf.yml` renders it to `assets/cv/CV_Oscar_Lopez_Ruiz.pdf` on push.
- `sitemap.xml`, `robots.txt`, `llms.txt` — search and AI crawler metadata.
